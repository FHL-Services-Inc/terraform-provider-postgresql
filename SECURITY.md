# Security policy

## Supported versions

Security fixes go into the latest minor release only. Older versions are not
patched; upgrade to the latest release.

## Reporting a vulnerability

Please don't report vulnerabilities in public issues or pull requests.

Report them privately through GitHub: open the repository's
[Security tab](https://github.com/FHL-Services-Inc/terraform-provider-postgresql/security)
and click "Report a vulnerability". Include the provider and PostgreSQL
versions, what an attacker can do and how to reproduce it.
